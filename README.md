# Baptiste Wetterwald Portfolio

Minimal repository for a bilingual personal portfolio for Baptiste Wetterwald, a graduated Engineer in Computer Science and Networks.

Primary positioning:

- Software Engineer - Backend / Full-stack.

Planned technical foundation:

- Angular frontend;
- Spring Boot backend;
- PostgreSQL;
- Docker-based deployment on a Linux VPS;
- Nginx reverse proxy for `bwetterwald.fr`.

No application code has been bootstrapped yet. The current phase is technical specification.
